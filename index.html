🌱 Nuestra Huerta Escolar

Este proyecto combina tecnología y agricultura para crear una huerta escolar automatizada, utilizando sensores de humedad y un sistema de riego para aprovechar mejor el agua.

📅 Ver calendario de siembra

⚙️ ¿Cómo funciona nuestro sistema?

💧

Sensor de humedad

El sensor mide la humedad de la tierra para saber si las plantas necesitan agua.

🧠

Control del sistema

El sistema analiza la información del sensor y determina cuándo es necesario activar el riego.

🚿

Riego automático

Cuando la tierra necesita agua, se activa el sistema de riego para mantener las plantas hidratadas.

Objetivo del Proyecto

Diseñar e implementar una huerta escolar automatizada que optimice la gestión del agua mediante sensores de humedad y riego programado, integrando conocimientos de automatización y producción sustentable.

Especies Cultivadas

  • Tomate Cherry: Requiere suelo húmedo constante y buena exposición solar.
  • Lechuga: Crecimiento rápido con riego frecuente y moderado.
  • Ajo: Necesita riego controlado para evitar el exceso de humedad en el bulbo.
  • Albahaca: Planta aromática ideal para repelencia natural de plagas.

Cronograma de Tareas

  1. Semana 1: Preparación del terreno y medición de parámetros del suelo.
  2. Semana 2: Siembra de semillas y plantación de albahaca y lechuga.
  3. Semana 3: Instalación de sensores de humedad y calibración.
  4. Semana 4: Supervisión del sistema de riego y control de crecimiento.
