# 🌱 Huerta Escolar Automatizada

Proyecto realizado por estudiantes de la E.E.S.T. N°1 "Julio A. Roca".

## 📌 Descripción

Este proyecto consiste en el diseño de una huerta escolar automatizada que busca mejorar el cuidado de los cultivos mediante sensores de humedad y un sistema de riego controlado.

La página web permite conocer el proyecto, las especies cultivadas, el cronograma de tareas y un calendario de siembra según las estaciones del año.

## 🎯 Objetivo del proyecto

Crear una herramienta digital para acompañar una huerta escolar, facilitando la organización de cultivos y el control de tareas mediante tecnologías web.
