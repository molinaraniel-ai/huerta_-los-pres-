## Mejora 1: Diseño responsive

**Prompt utilizado:**

"El sitio no es responsive en pantallas menores a 600px. Agregá una media query para que el diseño se adapte a celulares."

**Término técnico aprendido:**

Media query: permite cambiar los estilos de una página según el tamaño de pantalla.
